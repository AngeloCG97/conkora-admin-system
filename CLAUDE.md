# conkora-admin-system

## Agent skills

### Issue tracker

Los issues se gestionan en GitHub Issues (AngeloCG97/conkora-admin-system) con el CLI `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Se usan los nombres por defecto: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Un solo contexto: `CONTEXT.md` y `docs/adr/` en la raíz. See `docs/agents/domain.md`.

### Code conventions

Layout, commands (`npm run check`, `npm test`) and how to add tables, Hasura permissions, SQL views, endpoints and pages: `docs/agents/conventions.md`.
